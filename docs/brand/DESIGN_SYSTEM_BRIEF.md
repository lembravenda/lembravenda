# Design System Brief

## Direção aplicada na Sprint Visual Premium v1

O LembraVenda passou a usar o território visual `Calor Profissional`.

Objetivo da interface:

- parecer ferramenta pronta;
- transmitir confiança e organização;
- manter leveza no celular;
- guiar a próxima ação com clareza;
- evitar aparência de dashboard corporativo ou app genérico.

## Tokens aplicados

### Cores principais

- `primary`: `#2E7D57`
- `primary-dark`: `#1A5C40`
- `primary-light`: `#EAF4EF`
- `accent`: `#F5A623`
- `accent-light`: `#FFF9E6`
- `background`: `#F5F0E8`
- `surface`: `#FFFFFF`
- `foreground`: `#111827`
- `text-secondary`: `#6B7280`
- `success`: `#16A34A`
- `danger`: `#DC2626`
- `border`: `#E5E7EB`

### Superfícies

- fundo geral com sensação pedra-quente;
- cards brancos como superfície principal;
- blocos auxiliares em tom `muted` para contraste suave;
- badges e chips usando verde claro, âmbar claro e estados suaves.

### Sombras e radius

- card principal com sombra leve;
- elevação maior apenas para hero mockup e navegação fixa;
- cantos arredondados consistentes, sem excesso.

## Componentes principais aplicados

- `BrandLogo`
- `AppCard`
- `SubmitButton` com variantes consistentes
- `StatusBadge`
- `EmptyState`
- `SectionHeader`
- `AppHeader`
- `FeatureCard`
- `StepCard`

## Padrões de interação

- botões principais full-width quando o contexto pede ação clara;
- alvos de toque confortáveis, preferencialmente `44px+`;
- formulários com labels visíveis e helpers curtos;
- empty states sempre com contexto e próximo passo.

## O que a interface deve evitar

- roxo dominante;
- azul corporativo frio;
- visual “painel enterprise”;
- densidade alta demais no mobile;
- termos técnicos visíveis para usuário final.

## Itens para v2

- estados ativos na navegação inferior;
- refinamento de ícones próprios de produto;
- revisão visual completa dos estados de loading e erro;
- biblioteca mais explícita de tokens para dark mode, se um dia fizer sentido.

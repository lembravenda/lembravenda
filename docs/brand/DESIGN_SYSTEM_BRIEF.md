# Design System Brief

## Componentes necessários

- botões
- cards
- inputs
- nav inferior
- empty states
- badges
- alerts
- forms
- cards de pricing, se necessário futuramente

## Tokens iniciais

- cor primária
- escala de neutros
- spacing
- radius
- shadows
- tipografia

## Requisitos de interface

- mobile-first
- toque confortável
- textos legíveis
- CTAs claros
- consistência entre landing e app

## O que o design system deve evitar

- excesso de ornamento
- visual “dashboard enterprise”
- densidade visual alta demais para telas pequenas

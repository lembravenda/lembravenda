# Histórias de usuário

## Autenticação

- Como revendedora, quero criar uma conta para acessar meus dados com segurança.
- Como revendedora, quero entrar novamente na minha conta para continuar meu trabalho.
- Como revendedora, quero sair da conta para proteger meus dados em um celular compartilhado.

## Perfil da revendedora

- Como revendedora, quero cadastrar meu nome, marca, telefone e chave Pix para usar essas informações nas mensagens.
- Como revendedora, quero editar meu perfil quando meus dados mudarem.

## Clientes

- Como revendedora, quero cadastrar clientes com nome, telefone e observações para organizar meus contatos de venda.
- Como revendedora, quero buscar clientes para encontrar rapidamente quem estou atendendo.
- Como revendedora, quero editar ou remover clientes quando necessário.

## Produtos

- Como revendedora, quero cadastrar produtos com nome, preço e frequência estimada de recompra.
- Como revendedora, quero editar produtos para manter preços atualizados.
- Como revendedora, quero desativar ou remover produtos que não vendo mais.

## Pedidos

- Como revendedora, quero criar pedidos com cliente, produtos, quantidades e valores.
- Como revendedora, quero acompanhar separadamente se o pedido foi pago e se foi entregue.
- Como revendedora, quero consultar o histórico de pedidos de um cliente.

## Cobrança

- Como revendedora, quero gerar uma mensagem de cobrança com resumo do pedido e chave Pix para enviar manualmente.
- Como revendedora, quero copiar a mensagem de cobrança para colar no WhatsApp.
- Como revendedora, quero abrir o WhatsApp manualmente com a mensagem preenchida quando houver telefone.

## Recompra

- Como revendedora, quero receber lembretes de recompra para chamar clientes no momento certo.
- Como revendedora, quero copiar uma mensagem de recompra para enviar manualmente.
- Como revendedora, quero marcar uma oportunidade como contatada.

## Tela Hoje

- Como revendedora, quero ver o que preciso fazer hoje para não esquecer cobranças, entregas e recompras.
- Como revendedora, quero concluir ações direto da tela "Hoje" para trabalhar mais rápido no celular.

## Configurações

- Como revendedora, quero revisar meus dados de perfil e preferências.
- Como revendedora, quero entender como as mensagens prontas funcionam antes de enviar.
- Como revendedora, quero sair da minha conta com segurança quando terminar o uso.
